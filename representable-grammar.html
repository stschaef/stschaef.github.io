Definition. Representable Grammars

2026-08-24 · lambekd intrinsically-correct parsing

For any string 𝑤, we can define a representable grammar ⌈𝑤⌉ which matches exactly the string 𝑤 and nothing else. The parse trees for a representable grammar are proofs that the string is exactly equal to 𝑤:

⌈𝑤⌉(𝑢)=(𝑢≡𝑤)
