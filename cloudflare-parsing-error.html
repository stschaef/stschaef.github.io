Cloudflare Parsing Error

2025-04-29 · link · parsing security cve bug

An error in the Cloudflare HTML parser would allow uninitialized memory to be dumped when there were imbalanced HTML tags.

This is indeed a case where a verified parser would have alleviated the issue.
