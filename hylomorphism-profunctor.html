Definition. The hylomorphism profunctor

category-theory F-algebra F-coalgebra

Fix an endofunctor 𝐹:𝒞︀→𝒞︀. Hylomorphisms form a profunctor from coalgebras to algebras,

𝖧𝗒𝗅𝗈:𝖢𝗈𝖺𝗅𝗀(𝐹)op×𝖠𝗅𝗀(𝐹)→𝐒𝐞𝐭,

where 𝖧𝗒𝗅𝗈((𝑋,𝛾),(𝐵,𝛼)) is the set of ℎ:𝑋→𝐵 with ℎ=𝛾⋆𝐹ℎ⋆𝛼.

The action is by composition. If 𝑔:(𝑌,𝛿)→(𝑋,𝛾) is a coalgebra morphism (𝑔⋆𝛾=𝛿⋆𝐹𝑔) and 𝑘:(𝐵,𝛼)→(𝐵′,𝛼′) is an algebra morphism (𝛼⋆𝑘=𝐹𝑘⋆𝛼′), then 𝑔⋆ℎ⋆𝑘 is again a hylomorphism:

𝛿⋆𝐹(𝑔⋆ℎ⋆𝑘)⋆𝛼′=𝛿⋆𝐹𝑔⋆𝐹ℎ⋆𝛼⋆𝑘=𝑔⋆𝛾⋆𝐹ℎ⋆𝛼⋆𝑘=𝑔⋆ℎ⋆𝑘.

In these terms, a coalgebra 𝛾 is recursive when 𝖧𝗒𝗅𝗈(𝛾,−) is the terminal functor, and an algebra 𝛼 is corecursive when 𝖧𝗒𝗅𝗈(−,𝛼) is. For the inverse of an initial algebra the profunctor is representable, 𝖧𝗒𝗅𝗈(𝗂𝗇−1,−)≅𝖠𝗅𝗀(𝐹)(𝗂𝗇,−), and dually 𝖧𝗒𝗅𝗈(−,𝗈𝗎𝗍−1)≅𝖢𝗈𝖺𝗅𝗀(𝐹)(−,𝗈𝗎𝗍) for a terminal coalgebra.

When every value of 𝖧𝗒𝗅𝗈 is a singleton, every divide-and-conquer specification over 𝐹 has exactly one solution. This is what local contractivity guarantees.
