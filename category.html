Definition. Category

2026-06-13 · Steven Schaefer · category-theory

A category 𝒞︀ consists of

  1. A type of objects 𝒞︀0
  2. For each pair of objects 𝑥,𝑦:𝒞︀0 a set of morphisms 𝒞︀(𝑥,𝑦). We may simply write a morphism with an arrow, denote 𝑓:𝒞︀(𝑥,𝑦) as 𝑓:𝑥→𝑦 or 𝑥→𝑓𝑦 or similar
  3. A composition operation on morphisms. For 𝑓:𝑥→𝑦 and 𝑔:𝑦→𝑧, there is a morphism 𝑓⋆𝑔:𝑥→𝑧
  4. For each 𝑥:𝒞︀0, an identity morphism 𝗂𝖽𝑥:𝑥→𝑥

  5. Left-unitality of composition: for all 𝑓:𝑥→𝑦, an equality

    𝗂𝖽𝖫𝑓:𝗂𝖽𝑥⋆𝑓=𝑓

  6. Right-unitality of composition: for all 𝑓:𝑥→𝑦, an equality

    𝗂𝖽𝖱𝑓:𝑓⋆𝗂𝖽𝑦=𝑓

  7. Associativity of composition: for all 𝑓:𝑥→𝑦, 𝑔:𝑦→𝑧, ℎ:𝑧→𝑤, an equality

    𝖺𝗌𝗌𝗈𝖼𝑓,𝑔,ℎ:(𝑓⋆𝑔)⋆ℎ=𝑓⋆(𝑔⋆ℎ)

Concretely, the definition above is meant to model the one used in the Cubical standard library [1].

However, the notion of category is flexible. Depending on the context, we may be talking of small, locally small, wild, or any other kind of category that may augment which things we require to be (homotopy) sets, which things we require to be small types, etc. For the most part, the same idea of a category will apply across all of these settings.
